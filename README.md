# TweetStudio v84

This version restores normal frame rates instead of the ultra-low-FPS turbo profiles. Reel download quality selection now offers 1080p, 2K and 4K at both 30 FPS and 60 FPS.

Important: 30/60 FPS cannot be expected to export in the same time as the old v82 8–10 FPS profiles. A 60 FPS output contains up to 6x as many frames as a 10 FPS output and therefore requires substantially more decode/composite/encode work. The exporter still prefers hardware acceleration and realtime latency.
